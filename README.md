# umst-kanal

**Kanal** — continuous geometric-thermodynamic programming language.

Native denotation: continuous free-energy morphisms on multi-scale, multi-resolution SDF/FRep (or generalized wave) carriers under the single second-law axiom. Compiles to analogue wave functions / continuous physical processes. Discrete binary appears only as an explicitly costed projection for testing or legacy interfaces — never the native output.

First compiler host: Haskell (categorical and type-theoretic fidelity). Self-hosting path: successive Kanal compilers written in Kanal itself, improving under native Excitement + continuous closed-loop refinement.

Parallel to the UMST spines (umst-formal, umst-manifold, umst-formal-double-slit, umst-ucrs, ARCS, FFU, semantics).

## Constitution (non-negotiable)

- Sole physical root: the second law of thermodynamics (Clausius-Duhem style dissipation + Landauer observation cost).
- Every morphism is an admissible free-energy flow. Free-energy increase or conservation violation is a type error.
- Geometric carrier: multi-scale multi-resolution multi-dimensional SDF/FRep with exact algebraic / prime-spectral coefficients (drift-free identity).
- Program = compiler = realtime free-energy morphism. Syntax is the geometric embedding of continuous input signals.
- FFUs are Kanal programs: self-contained modular intelligences whose state is the geometric-thermodynamic carrier and whose transitions are Excitement.
- Real-time machine checking via entanglement / complementarity mathematics (from umst-formal-double-slit).
- Performance limited only by the quantum and thermodynamic physics of the substrate and sensors.

1. Operators and logic gates → continuous free-energy morphisms; Boolean only as costed dissipative projections.
2. Arithmetic and mathematical primitives → geometric / free-energy operations; discrete arithmetic as costed quantization.
3. Memory management → the multi-resolution SDF/FRep field *is* memory, meaning, state, knowledge. No discrete heap. Landauer-accounted erasure. Material imperfections typed as geometric features.
4. Control flow and composition → continuous Kleisli composition of admissible free-energy morphisms. Irreversibility of time is native.
5. Types and abstraction → continuous / hybrid dependent type theory indexed by free-energy cost, geometric resolution, scale, admissibility witnesses. λ-calculus + category theory + graph/DEC + algebraic number theory.
6. Syntax and surface language → geometric embedding of continuous signals (NL acoustic fields, sensors, kinematics, robot dynamics) into the shared carrier. Grammar = structure-preserving maps.
7. Compilation and execution → already collapsed. Realtime type checking + realization functors + native Excitement. Every step carries its witness.
8. Input / output and sensors → continuous bidirectional geometric-thermodynamic interfaces. All modalities embed into the same field language.
9. Concurrency, resources and time → ARCS-style typed resource morphisms + UCRS-style thermodynamic stamps intrinsic to every field state.
10. Self-correction and learning → native Excitement + continuous admissible refinement morphisms (graph-based liquid PPO style). Closed-loop learning cannot increase the global free-energy account.
11. Bare-metal performance and material grounding → realization functors to continuous substrate physics (charge, potential, quantum wave functions, chemical potentials, defects as features). Language understands the physics it realizes.
12. Formal verification and real-time machine checking → entanglement / complementarity mathematics in the continuous type theory. Self-hosting in the limit; discrete formal systems absorbed then superseded.
